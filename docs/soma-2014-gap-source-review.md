# Official source for the 15 SOMA Treasury gaps in 2014

Reviewed October 26, 2026. The user requested a reliable source for the 15 unavailable SOMA Treasury dates while preserving the current UI and colors.

## Verified official evidence

The New York Fed's [System Open Market Account Portfolio](https://www.newyorkfed.org/data-and-statistics/data-visualization/system-open-market-account-portfolio) loads an official script that directly reads this [aggregate summary JSON](https://www.newyorkfed.org/medialibrary/Interactives/markets/soma-interactive/soma-data/total-portfolio-summary.json). The script uses `soma.summary` and divides dollar values for chart display; the underlying file contains dollar-denominated component records in the same schema as the primary API. Two independent downloads and comparisons verified the linkage and exact numerical identity.

Both feeds contain 1,216 native dates from July 9, 2003 through October 21, 2026, with no duplicates. For **all 15 Wednesdays, February 5–May 14, 2014**, the visualization file publishes FRN as the literal string `"0"`, while the primary API has an exact empty string. Bills, notes/bonds, TIPS principal and TIPS inflation compensation match exactly on every affected date. Every nonblank value across all nine published component/total fields and the latest 104 full records also matches. The supplemental body is 448,487 bytes, SHA256 `14d492d23b832dfb14dba690621ccd3c954d0b93cdd4c6b29522dc1b20f5ec90`.

The visualization is a second official presentation of related SOMA data, **not an independent measurement**. Its historical file materializes 815 API blanks as published zeros: 567 FRNs and 248 agency entries. Its generator is not documented. The implementation therefore does not switch all history to this feed or generalize its blank-to-zero behavior.

Independent economic corroboration comes from the [May 20, 2014 operating policy](https://www.newyorkfed.org/markets/opolicy/operating_policy_140520.html) and the [2014 Domestic Open Market Operations report, printed page 7](https://www.newyorkfed.org/medialibrary/media/markets/omo/omo2014-pdf.pdf). The policy anticipated the first FRN reinvestment on July 31; the report confirms actual July FRN acquisitions and explains their exclusion from outright LSAP3 purchases. Accepting FRNs as collateral is separate from owning them in the Treasury portfolio. The summary's first positive FRN balance is August 6, 2014, $4,873,000, consistent with that chronology. This supports using the alternate published zeros for the 15 specifically reviewed weeks; anticipated policy alone would not establish actual holdings.

Other API/export formats retain blanks. Empty security-detail arrays also occur on unposted dates and cannot prove zero holdings. Historical H.4.1 releases corroborate all 15 candidate totals when rounded to millions, but differ by up to $490,529.82 because of precision. They are not spliced into this more precise series. No security identifiers or detail holdings are ingested.

## Narrow integration and failure behavior

The existing API remains primary. Only an exact blank FRN on one of the 15 enumerated target dates triggers a bounded supplemental download. The parser validates the supplemental dates and complete Treasury fields, requires an explicit numeric FRN zero and exact agreement of the other four inputs, and then calculates that date's Treasury-only total from the supplemental component set. Missing, malformed, duplicated, inconsistent or nonzero supplemental evidence rejects the candidate. Existing retries and last-good source retention remain in charge; no failed request can silently produce a zero or overwrite a complete source with guessed data. Lag in current visualization dates does not invalidate historical records whose dates and components match.

Recovered rows retain `primaryFrn:null`, record `frnStatus:'alternate-source'`, and identify the supplemental URL. Their numeric component zero is from that published alternate source, not a reclassification of the API blank. Registered observations and ordinary CSV rows use the alternate response's own hash and retrieval clock, with an explanatory footnote. All other dates keep their original numerical source. Admission permits only that exact URL, the explicitly declared two-source scope and those 15 dates; other providers, dates, URL variants and receipt bypasses remain rejected. Historical publication instants remain unknown.

The existing [New York Fed terms](https://www.newyorkfed.org/privacy/termsofuse.html) apply to these official aggregate facts and report-based context. Source title/URL, copyright, attribution, terms link, downstream conditions and identification of Meridian calculations are retained. This is conditional reuse rather than a public-domain claim. No new account, credential, paid provider or dependency is required.

Current page markup, charts, layout, theme and colors remain unchanged. Complete history stays in indicator/comparison views and ordinary CSV. Frozen results retain complete source/series inputs and the existing 36-Z.1/104-SOMA supplementary CSV scope. Existing captures and imported packages remain immutable.
