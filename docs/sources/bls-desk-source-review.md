Redirects, malformed/missing/unexpected/duplicate series, invalid numeric observations, periods and API messages fail the complete capture. ## Measurements

CES employment uses published seasonally adjusted thousands of payroll jobs. Eleven exhaustive supersectors (mining/logging, construction, manufacturing, trade/transportation/utilities, information, finance, professional/business, education/health, leisure/hospitality, other services and government) supply the reconciliation. Twelve narrower industries retain reference detail. These nested series are never additional reconciliation terms. Monthly changes use the exact previous calendar month; six-/twelve-month average changes require every intervening month. The latest eleven-supersector monthly sum reconciles to the total with a zero residual. Aerospace employment changes identify a measured industry change, not a causal strike estimate.

CPS levels retain thousands of people, distinctly from CES jobs. Published SA U-1 and U-2 use the civilian labor force denominator; U-4 adds discouraged workers; U-5/U-6 add all marginally attached. Official SA marginally attached (`LNS15026642`) and discouraged (`LNS15026645`) series are available, so the calculated denominator levels do not mix seasonal adjustments. The U-6 minus U-3 spread is percentage points, never people. Demographic rates use the named subgroup's civilian labor force, not the total labor force.

CES earnings separately retain official all-private hourly/weekly earnings and production/nonsupervisory hourly/weekly earnings and hours. Official weekly earnings are used directly, avoiding multiplication of rounded hourly/hourly-hours observations. Monthly dollar and percentage changes, three-/six-month compounded annualized growth use exact calendar baselines and are explicitly calculated.

ECI independently retains current-dollar index levels for compensation, wages/salaries and benefits across civilian, private-industry and state/local-government workers, each SA and NSA (18 native indexes). The base is December 2005=100. SA q/q growth is unannualized; annual growth uses the exact year-ago NSA index. These computed changes can differ from independently rounded BLS published rates. Civilian coverage excludes federal government. No benefit level is inferred by subtracting unrelated indexes.

PRS retains official nonfarm-business (sector 8500) output, hours, hourly compensation, real hourly compensation, productivity and unit-labor-cost indexes and published rate variants. Metadata verifies 2017=100 for current indexes. **Duration 1 is same-quarter-year-ago percent change; duration 2 is preceding-quarter change (published annual rate); duration 3 is the index.** Thus `PRS85006091` is productivity y/y, `PRS85006093` is its index, `PRS85006111` is ULC y/y and `PRS85006113` is its index. This corrects the proposed inventory's mistaken *93/*13 annual-rate labels. Output uses measure 04, hours 03, nominal hourly compensation 10, real hourly compensation 15. Existing headline q/q annualized productivity/ULC rates remain in the original BLS source. No index is reconstructed by compounding rounded published rates.

[API terms](https://www.bls.gov/developers/termsOfService.htm) require an access date and a disclaimer. Every series retains attribution, a rights URL and this required statement: “BLS.gov cannot vouch for the data or analyses derived from these data after the data have been retrieved from BLS.gov.” BLS trademarks/logos are not granted by these terms. The UI should display the source access date and disclaimer with exports/source information.

## Admission, tests and remaining source work

`validateBlsDeskSource(source)` is browser safe and returns a boolean. The server `assertBlsDeskSource(source)` throws on rejection; `assertBlsDeskData(snapshot)` validates the additive snapshot family. Exact source code, units, adjustment, frequency, observation type, scope, required notices, requested-series receipts and actual capture time must match. Native values must match retained source strings; calculations are rebuilt from admitted native rows and checked independently of saved derived values. Missing datasets cannot become a partially valid `blsDesk` source.

Focused tests were observed failing before the contracts were implemented, then passing. They cover missing/extra/duplicate scope, invalid periods/numbers, null suppressions, exact missing baselines, distinct PRS levels versus rates, ECI SA/NSA horizons, nonoverlapping CES reconciliation, tampered native/derived/import lineage, terms notices, all official metadata and actual-response parsing. Candidate admission was run against the complete genuine response capture.

This timeseries source does not carry CES original first/second/final release vintages, collection-response rates, release-specific uncertainty intervals, strike attribution, CPS survey response rates or productivity capital-deepening/TFP attribution. These must come from separately reviewed official publication/response-rate evidence, where available, rather than being inferred from latest revised history or copied from reference examples. Existing publication archives may supply some vintage slots; the UI must identify the precise retained coverage. The source also does not add Atlanta Fed matched-individual wage growth, which is a separate official Fed dataset with different scope.
