# Source reviews

These retained reviews record the exact datasets, interpretation, provenance and reuse scope considered for Meridian.
They are rights evidence; an entry in this index does not extend a review's scope or grant permission for other material.

[research source ledger](../research-dashboard-sources.md) for policy and admission context.
The [expectations and policy-path dependency review](../expectations-policy-path-dependencies.md)
records investigated sources and remaining dependencies; it admits no additional observations.
