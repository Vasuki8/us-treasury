## Coverage, identity and interpretation

There are **168 facts**, four per PDF: initial advance, its same-release revised/unrevised prior comparison, continued advance, and its independent prior comparison. Each measurement has 84 facts across 43 reference weeks. Initial advances cover January 3–October 17, 2026; continued advances cover December 27, 2025–October 10, 2026. Prior comparisons extend one week earlier. Every linked release and advance-week sequence within this reviewed span is contiguous by seven days. This is not a claim of a completed calendar 2026, a January 1 release, or coverage before January 8.

Identity includes measurement, original Saturday reference week, publication day and role. `InitialClaims/SA/Release` and `ContinuedClaims/SA/Release` are Meridian semantic PDF field mappings, not agency API codes. Original count strings remain intact; displayed values divide counts by 1,000. Continued claims are insured unemployment/continued weeks claimed, not unique people or the total unemployed population. Both measures retain independent reference weeks.

Advance is explicitly identified by the dated source. Prior comparisons keep the source's revised/unrevised wording and quoted earlier count. That quoted count does not create a separately retained advance publication. For the earliest edge week, the original advance is unavailable even though a prior comparison exists. As-published selection filters measurement before reference week and cutoff. It never substitutes the XML series or current release context. Differences are calculated only between compatible published values for the same measurement/week; they do not establish revision causes.

Publication dates have **day precision**; `publishedAt:null` deliberately leaves the exact publication instant unknown. The printed 08:30 Eastern embargo is scheduled timing, not historical server-publication evidence. Actual UTC retrieval and PDF SHA256 remain separate. All newly captured publication facts were retrieved **2026-10-22T21:37:36.638Z–21:37:50.134Z**. They do not establish Meridian capture history before those retrievals.

It does not say the update was already applied on March 12. The [March 19 release](https://oui.doleta.gov/press/2026/031926.pdf) explicitly applies the annual seasonal-factor revision from 2021 forward. Separate source-specific paraphrases and scheduled/applied labels are retained. A difference crossing that source-noted applied update is withheld; later ordinary differences are not automatically attributed to it. The archive retains the selected four facts per PDF, not every historical value affected by annual updates or a complete account of later revisions.

Older real PDFs include a spaced release-day glyph, an optional `by` in prior revision prose, and a factual lowest-level aside. Parser tests cover those bounded variants while preserving date, signed arithmetic and independent SA table checks. Unknown source notices/layouts fail closed.

## Storage and collection

`src/claims-publication-archive.js` is a separate data-only, append-only module (322,994 bytes for this batch). `scripts/dol-publication-policy.mjs` enforces exact reviewed identities, count tokens, units, roles, notices, source paths, day precision, source attribution and typed retrieval evidence. Build requires the complete 168-fact scope. Tampered numeric values/raw tokens, invalid metadata or an incomplete archive block publication. The printed-zero correction also requires its exact reviewed PDF hash.

Run `node scripts/capture-claims-publications.mjs` after installing the existing lockfile. The collector uses the existing bounded PDF worker, requests each required PDF only once sequentially, validates all four facts before selecting a subset, and rejects unexpected redirects, errors and unsafe/changed layouts. The writer locks before a fresh data-only read, appends only missing admitted IDs and atomically replaces the archive after complete validation. Retained records/provenance are never overwritten; a complete rerun performs no fetch and changes no bytes. Future scope expansions require a source review and manifest update. Daily latest-context refresh and immutable capture replay continue independently; the archived batch is not automatically rediscovered each day. No new dependency, service, credential or hosting is added.

The browser loads the claims archive only for a selected claims publication view; GDP and claims have independent cache/retry/error state. Week-scoped CSVs and frozen packages retain selected release facts, roles, raw counts, rights, notices and actual receipts. Existing BEA publication records, explanation records and package contracts remain unchanged. Original observations, calendars and all 36 immutable capture files/index entries are unchanged by this addition.
